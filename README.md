# Matatena Records — Espacio de Composición y Creatividad

Aplicación web editorial e interactiva para **Matatena Records**, un estudio musical diseñado bajo el concepto de generar ideas, componer y experimentar como en el juego clásico de la **Matatena**.

## Modelo de Negocio ("Las Jugadas")

1. **Renta de Estudio Personalizado** *(4 horas incluidas + \$400.00 MXN por hora extra)*:
   - **Grado I · "De a Una" (\$2,000.00 MXN)**: Solo espacio + consola + instrumentos. Sin ingeniero ni productor. El cliente opera los programas (DAW) y toca los instrumentos.
   - **Grado II · "De a Dos" (\$3,000.00 MXN)**: Espacio + instrumentos + Ingeniero de grabación y/o Productor.
   - **Grado III · "De a Tres" (\$4,000.00 MXN)**: Espacio + instrumentos + Ingeniero + Compositor en sesión.
2. **Experiencia Compositora · "Ronda Colectiva" (\$4,500.00 MXN)**:
   - Experiencia musical guiada por el fundador y artistas invitados para una persona o grupos/comunidad de **todas las edades**.
3. **Renta de Espacio para Uso Múltiple · "Mesa Abierta" (Cotización Personalizada)**:
   - Listening parties para lanzamientos de disco, showcases con música o instrumentos en vivo (sin necesidad de usar la consola) y actividades culturales.

## Inventario Base ("1 Sala · 1 Consola · 2 de Cada Pieza")

- **1 Sala Creativa** + **1 Consola Central**
- **2 Guitarras**, **2 Baterías**, **2 Pianos**, **2 Sintetizadores**, **2 Bajos**, **2 Micrófonos Estelares** y **2 Entornos DAW**, todos editables desde `/admin`.

## Comandos

```bash
npm run test       # Ejecuta las pruebas automatizadas con Vitest
npm run db:setup   # Sincroniza esquema e inventario con Supabase
npm run dev        # Inicia el servidor local en http://localhost:3000
npm run build      # Compila para producción
```
